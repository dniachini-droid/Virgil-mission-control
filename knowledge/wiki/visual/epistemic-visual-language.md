# Epistemic visual language

The contract is data in `packages/visual-language` and prose in the art bible (`docs/art-direction/`). Durable compiled knowledge is a solid celestial structure; immutable raw evidence a sealed source artifact; an owner decision a sealed monument with an authority mark; a hypothesis a translucent projection; a contested claim an interference or bifurcated node; a superseded claim a faded structure with a successor tether; an unverified claim an unstable object with an incomplete tether; live operational state a moving signal, never a memory object; a deterministically verified fact carries a machine-verification signature. The Operational Animation Grammar (Amendment 1) applies the same discipline to the Foundry: reading never resembles editing, skipped never resembles passed, eligibility never opens the airlock. Roles are recognisable by silhouette and instrument ([[agent-roster]]).
