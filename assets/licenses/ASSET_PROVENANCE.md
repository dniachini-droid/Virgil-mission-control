# Asset provenance register

Maintained register for every file imported under `assets/` and `docs/art-direction/approved/`. The owner's own bundle statement is preserved verbatim at `docs/art-direction/approved/bundle/ASSET_PROVENANCE.md`; this register restates it per file and records what was and was not verified from a primary source during the consolidation session.

Categories: approved visual reference; character concept sheet; candidate 3D model; production-ready runtime asset. Verification vocabulary: **verified** (primary source read and recorded), **stated** (asserted by the bundle, not independently verified), **owner attestation, not verified** (the owner has asserted the rights in their own words in an owner decision; no licence text has been read by anybody — see `docs/decisions/OD-0008-meshy-licence-attestation.md`), **not verified**.

Licence basis: **`docs/decisions/OD-0008-meshy-licence-attestation.md`** (owner decision, authority layer 1, accepted 2026-09-07). The owner attested in the owner console that they hold a paid Meshy subscription and that they accept they have the commercial rights to use models generated with it in this project. Verification: **owner attestation, not verified.**

What that phrase means, and it is not softened: nobody has read Meshy's Terms of Service. Not the owner, not any session. The Meshy asset page shows only a visibility setting reading "private", which governs whether other Meshy users can browse the asset and says nothing about what rights the owner holds in the downloaded file. `.claude/settings.json` denies `WebFetch` and `WebSearch`, so no session in this repository can retrieve the terms. If Meshy's terms reserve rights in generated output, restrict commercial use, or condition rights on an active subscription, OD-0008 does not change that; it fixes responsibility for having proceeded without checking. Unlike `assets/models/candidates/virgil-model-candidate-01.glb`, which derives from the owner's own reference artwork, a text-prompt-generated Meshy model has no owner-supplied input artwork in it, so the attestation carries the whole licence weight.
