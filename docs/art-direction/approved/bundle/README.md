## Approved art direction

Virgil is a charming psychedelic space-operations world populated by compact, expressive, screen-faced astro-bots with funny and highly distinctive equipment.

The approved production direction combines:

- readable, practical worker proportions and stations;
- celestial retro-futurist architecture;
- vivid teal, violet and magenta cosmic environments;
- warm tactile foreground lighting;
- evidence-driven operational choreography;
- premium stylisation rather than realism.

Virgil is a compact senior command robot with crescent communications equipment, navigation vanes, a rigid command mantle and an orrery-based control centre. He conducts work but never performs a protected worker role.
