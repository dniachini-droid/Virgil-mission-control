## Conventions

- Packages export TypeScript source (`exports: ./src/index.ts`); the app bundles them. Build outputs are not committed.
- JSON data that carries authority or contracts is validated at import time (`packages/visual-language`) or by tests (`constitution/*.json`).
- Generated files (`schemas/`, `seed-graph.json`) are regenerated by scripts and excluded from formatting.
- Per-package `typecheck` and `test` run through Turborepo; `pnpm check` runs lint, typecheck and tests for the workspace.
